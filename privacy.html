Privacy Policy

Last updated: October 2, 2026

Hermes is a personal AI assistant that Lucas Marshall ("the operator") runs for his own use. This policy explains how Hermes handles data from Google accounts.

Who can use it

Hermes is not a public service. Only the operator signs in with his own Google account.

Data accessed

With the operator's permission, Hermes can access Gmail, Google Calendar, Google Drive, Google Contacts, Google Sheets and Google Docs data. It does this only when the operator asks it to do something that needs that data.

How data is used and stored

  • Google OAuth tokens are stored only on the operator's own computer.
  • Google data is used only to complete the operator's requests. It is not sold, shared with third parties, or used for advertising.
  • To answer a request, parts of the relevant data may be sent to the AI model provider the operator has configured.
  • Hermes does not run any server or database that collects Google user data.

Google API Services User Data Policy

Hermes's use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions. Revoking access makes the stored token stop working.
